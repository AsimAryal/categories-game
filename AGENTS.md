# Categories project guide

## Scope

These instructions apply to the entire repository.

## Architecture

- `app/` is the Python 3.11 FastAPI server. It owns game rules, room state, WebSocket authorization, timers, and SQLite persistence.
- `frontend/` is the Preact + TypeScript + Vite PWA. It renders server-authoritative state and sends user intentions over `/ws`.
- `frontend/dist/` is generated by `npm run build`; never edit it by hand.
- The old `static/` vanilla client was removed; do not reintroduce a second frontend.
- `game_data.db` is runtime data and must never be committed.

## Commands

- Install backend: `uv sync`
- Run backend: `uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1`
- Install frontend: `cd frontend && npm ci`
- Run frontend dev server: `cd frontend && npm run dev`
- Build frontend: `cd frontend && npm run build`
- Backend tests: `uv run pytest`
- Frontend checks: `cd frontend && npm run typecheck && npm test && npm run build`

## Invariants

- Treat the server as authoritative for phases, permissions, deadlines, submissions, and scores.
- Only the current host may start/advance/end a game or change settings.
- Keep `MessageType` and Pydantic payloads in `app/game/models.py` synchronized with TypeScript types and handlers in `frontend/src/game/`.
- Validate state transitions and payloads on the server; hiding a client control is not authorization.
- Use absolute Unix timestamps for multiplayer deadlines. Client timers are display-only.
- Preserve reconnect compatibility when adding persisted model fields by providing safe defaults.
- Run Uvicorn with exactly one worker; rooms and WebSocket connections are process-local.

## Frontend conventions

- Prefer small Preact components, typed props, semantic HTML, and text rendering over raw `innerHTML`.
- Keep primary touch targets at least 44px and account for safe-area insets and mobile keyboards.
- Every async state needs clear connecting, empty, error, disabled, or recovery feedback.
- Respect light/dark themes and `prefers-reduced-motion`.
- Do not add remote font or asset dependencies that make the Pi-hosted app depend on a third party.

## Verification

- Add regression coverage for any changed game rule or reconnect path.
- Before handoff, run Python tests, frontend type checks/tests, and a production PWA build.
- For protocol or timer work, manually verify two independent clients, disconnect/reconnect, and a backgrounded phone-sized viewport.

## Raspberry Pi deployment

- Build the frontend before starting FastAPI; FastAPI serves `frontend/dist/`.
- Keep `game_data.db` writable by the service user.
- Cloudflare Tunnel supplies HTTPS for installable PWA behavior and must pass WebSocket upgrades on `/ws`.
- Do not commit tunnel credentials, service tokens, database files, or environment secrets.
